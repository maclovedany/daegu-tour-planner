# 플래너 — 기획자 화면

조건 네 가지만 고르면 코스 초안까지 이어서 만들고, 3D 지도와 홍보물 시안으로 보여 주는 화면이다.
기존 관리자 화면(`관리자조회.py`)과 따로 띄우며, 같은 `runs/` 기록을 읽고 쓴다. 기존 앱 파일은 고치지 않았다.

## 켜기

```bash
cd app
.venv/bin/python 플래너/서버.py --port 8770     # http://127.0.0.1:8770/
```

## 화면

| 주소 | 내용 |
|---|---|
| `/` | 시작 화면. 조건을 고르고 "기획 시작"을 누르면 자료 확인 → 수요 분석 → 코스 짜기가 이어서 진행되고, 위쪽에 단계가 표시된다 |
| `/?id=<실행id>` | 코스 3D 지도. 핀, 동선(1일차 파란 실선 · 2일차 빨간 점선), 경로를 걷는 너구리·족제비, 일정과 근거·주의 |
| `/promo.html?id=<실행id>` | 홍보물 시안 6종: 관광 지도, 리플릿, 포스터, SNS 카드뉴스, 스탬프 투어 북, 적용 예시 |

## 파일로 내보내기

```bash
pip install playwright                                   # 한 번만. 설치된 Chrome을 쓴다
python 플래너/홍보물_내보내기.py "<실행id>"                  # runs/<실행id>/홍보물/ 에 PDF · PNG

python 플래너/영상자료.py "<실행id>"                        # 영상/public/course.json
cd 플래너/영상 && npm install && npm run render            # 영상/out/course.mp4 (1080x1920)
```

## 에이전트 구성

| 에이전트 | 하는 일 | 걸리는 시간 (실측) |
|---|---|---|
| 총괄 | 단계 에이전트와 검증 에이전트를 스스로 부르고, 걸린 단계를 지시와 함께 다시 돌릴지 정한다 (`걸음.py`) | 판단 한 번에 3~5초 |
| 자료 확인 | 조건에 맞는 근거 행과 경고를 CSV에서 코드로 뽑는다 (`근거추출.py`, AI 없음) | 0.1초 이내 |
| 수요 분석 | 근거표를 보고 요약과 해석만 쓴다 | 8~20초 |
| 코스 짜기 | 지침과 장소 자료를 한 번에 받아 코스 초안 JSON을 쓴다. 담당자 식사 선택 등은 코드가 맞춘다 | 34~60초 (제한 1분) |
| 검증 | 만든 에이전트와 따로 요약 · 코스를 자료와 대조한다 | 5~10초 |

- 단계 제한은 모두 1분이다. 넘으면 끊고 총괄이 다시 부르거나 마무리한다.
- 총괄은 담당자만 정할 수 있는 것(시작 · 종료, 식사, 확정)을 정하지 못한다. 그런 항목은 "사람이 정할 것"으로 넘긴다.
- 예전의 고정 순서 실행은 `실행.py`에 남아 있다.

## Vercel 배포판

- 진입점은 `app/index.py`이다 (Vercel 프로젝트의 Root Directory가 `app`).
- 로컬과 같은 에이전트 엔진(`걸음.py`)을 쓴다. 서버가 요청 한 번에 한 걸음만 하고, 화면이 `/api/step`을 되풀이해 부른다. 상태와 결과는 Supabase에 둔다 (`구름.py`).
- 환경변수: `GEMINI_API_KEY`(필수), `GEMINI_MODEL`(선택, 기본 `gemini-3.8-flash`), `SUPABASE_URL`, `SUPABASE_ANON_KEY`. `HARUHARU_ACCESS_CODE`를 넣으면 그 코드를 아는 사람만 새 기획을 만든다.
- Supabase에는 `supabase/migrations/`의 두 파일을 이름 순서대로 실행하고, 장소 자료는 `supabase/seed.sql`로 넣는다.
- 배포판은 `app/` 밖을 볼 수 없다. 지침이나 자료를 고쳤으면 `python 플래너/견본_만들기.py`로 `묶음/`과 `견본/`을 다시 만들고 커밋한다.
- 홍보 문구 만들기와 PDF · 영상 내보내기는 아직 로컬에서만 된다.

## 알아 둘 점

- 근거 행을 고르는 규칙은 지침(자료 고르기 · 데이터 목록)을 코드로 옮긴 것이다. 지침에 없는 기준 하나를 더했다: KOSIS 항목이 많은 표는 구분마다 상위 5개와 닭 · 치킨 항목만 싣는다.
- 자동 진행은 1·2단계의 담당자 선택을 "남기고 진행"으로 처리하고, 선택 기록에 자동 처리였음을 남긴다.
- 홍보 문구는 코스 **확정 전 초안**으로도 4단계를 실행해 만든다. 기존 통합시험 규칙(확정 뒤에만 4단계)과 다르며, 모든 시안에 "초안" 표시가 들어간다.
- 지도 바탕(`화면/map.json`)과 장소 좌표(`자료/장소좌표.csv`)는 OpenStreetMap에서 2026-11-23에 받은 것이다. 좌표가 없는 장소는 지도에 놓지 않는다.
- 동선은 장소를 순서대로 잇는 곡선이며 실제 이동 경로가 아니다.
- 캐릭터 그림은 이예진 브랜치 `캐릭터디자인_예시/`의 v1.1 디자인 시트에서 포즈를 오려 낸 것이다.
- Remotion은 4인 이상 회사에서 쓰면 유료 라이선스 대상이다.
