# 플래너 — 기획자 화면

조건 네 가지만 고르면 코스 초안까지 이어서 만들고, 3D 지도와 홍보물 시안으로 보여 주는 화면이다.
기존 관리자 화면(`관리자조회.py`)과 따로 띄우며, 같은 `runs/` 기록을 읽고 쓴다. 기존 앱 파일은 고치지 않았다.

## 켜기

```bash
cd app
.venv/bin/python 플래너/서버.py --port 8770     # http://127.0.0.1:8770/
```

## 화면

| 주소 | 내용 |
|---|---|
| `/` | 시작 화면. 조건을 고르고 "기획 시작"을 누르면 자료 확인 → 수요 분석 → 코스 짜기가 이어서 진행되고, 위쪽에 단계가 표시된다 |
| `/?id=<실행id>` | 코스 3D 지도. 핀, 동선(1일차 파란 실선 · 2일차 빨간 점선), 경로를 걷는 너구리·족제비, 일정과 근거·주의 |
| `/promo.html?id=<실행id>` | 홍보물 시안 6종: 관광 지도, 리플릿, 포스터, SNS 카드뉴스, 스탬프 투어 북, 적용 예시 |

## 파일로 내보내기

```bash
pip install playwright                                   # 한 번만. 설치된 Chrome을 쓴다
python 플래너/홍보물_내보내기.py "<실행id>"                  # runs/<실행id>/홍보물/ 에 PDF · PNG

python 플래너/영상자료.py "<실행id>"                        # 영상/public/course.json
cd 플래너/영상 && npm install && npm run render            # 영상/out/course.mp4 (1080x1920)
```

## 알아 둘 점

- 자동 진행은 1·2단계의 담당자 선택을 "남기고 진행"으로 처리하고, 선택 기록에 자동 처리였음을 남긴다.
- 홍보 문구는 코스 **확정 전 초안**으로도 4단계를 실행해 만든다. 기존 통합시험 규칙(확정 뒤에만 4단계)과 다르며, 모든 시안에 "초안" 표시가 들어간다.
- 지도 바탕(`화면/map.json`)과 장소 좌표(`자료/장소좌표.csv`)는 OpenStreetMap에서 2026-11-23에 받은 것이다. 좌표가 없는 장소는 지도에 놓지 않는다.
- 동선은 장소를 순서대로 잇는 곡선이며 실제 이동 경로가 아니다.
- 캐릭터 그림은 이예진 브랜치 `캐릭터디자인_예시/`의 v1.1 디자인 시트에서 포즈를 오려 낸 것이다.
- Remotion은 4인 이상 회사에서 쓰면 유료 라이선스 대상이다.
